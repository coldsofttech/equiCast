equiCast — design tokens

Three palettes to choose from

A reuses Resource Planner's tokens exactly. B and C keep the same structural system — spacing, radius, type, shadow — and only change the hue story, so this is a color decision, not a redesign. Each preview below is built from real equiCast UI (topbar, menu, a stat card, a holdings row, buttons, status badges) shown in both light and dark.

Nothing here is final — pick one outright, or mix pieces (e.g. Option A's neutrals with Option B's accent). Whichever direction wins becomes the --ec-* token set for Phase 0.
